How to get your Google client ID and secret (about 10 minutes, once)
  1. Open console.cloud.google.com and create a project (any name).
  2. Go to APIs & Services → Library, search for YouTube Data API v3 and press Enable.
  3. Go to OAuth consent screen: choose External, fill in the app name and your email. Under Test users, add the Google account that owns your channel.
  4. Go to Credentials → Create credentials → OAuth client ID. Choose Desktop app. Copy the client ID and secret here.

Updates

QuizCaster checks GitHub for new versions once every six hours. It only tells you; it never installs anything during a show.

FFmpeg missing

Needed to go live

FFmpeg sends the video to YouTube. Install it and restart QuizCaster: Windows winget install Gyan.FFmpeg, macOS brew install ffmpeg, Linux sudo apt install ffmpeg. Previews work without it.
